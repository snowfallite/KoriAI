# Иконки

Три линейные иконки 16×16, линия 1.25px, квадратные концы, чернила #000000: `sound` (озвучить), `copy` (копировать), `check` (в словаре).

Остальные знаки интерфейса — глифы JetBrains Mono, а не иконки: → ↓ ↑ + × ⌄. В коде вставляйте SVG инлайн со `stroke="currentColor"`, чтобы иконка брала цвет текста; файлы здесь — для макетов. Иконка всегда стоит в квадратной ячейке 36px (28px в mind-map).
