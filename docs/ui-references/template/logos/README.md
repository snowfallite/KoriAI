# Логотипы

Все файлы — кривые из JetBrains Mono Regular (кана — Noto Sans JP Light), одноцветные: `-black` (#000000) для светлых фонов, `red` и `grey-200`; `-white` (#FFFFFF) для `black` и `grey-900`.

- `kioku-spaced-*.svg` — разреженный K Ï O K U с き お く под Ï O K. Hero, обложки, первый слайд. Минимум 160px в ширину.
- `kioku-wordmark-*.svg` — компактный Kïoku с надстрочной きおく. Шапки, подвал, документы. Минимум 64px.
- `ki-mark-*.svg` — знак Kï. Аватары, короткие подписи. Минимум 16px.
- `ki-icon.svg` — иконка расширения: белый квадрат, чёрная рамка, Kï. Тулбар браузера, фавикон, стор.

Охранное поле — высота буквы K. Не перекрашивайте в red, не растягивайте, не меняйте трекинг.
