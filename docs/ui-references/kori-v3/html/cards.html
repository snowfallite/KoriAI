Рамка вместо коробки

Серых заливок нет. Секция настроек держится на тонкой рамке и шапке капсом, сводка держится на числе, выбранное белое. Белые панели только там, где человек действует: ввод вопроса, вход, диалог.

Правила карточек

  • →Карточка это рамка 1 px без заливки. Шапка капсом, пояснение серым, действия внизу за линией.
  • →Сводка без рамки: подпись капсом, крупное число, между сводками вертикальная линия.
  • →Выбранная строка, вкладка и включённый переключатель белые.
  • →Главная кнопка: ячейка со стрелкой и подпись цветом текста. Удаление: та же кнопка с ячейкой red-deep. Знак × только у закрытия и ошибки.
  • →Уведомление: ячейка-знак слева (× ошибка, ↓ понижение, галочка готово, → справка), текст на #1A1A1A.
  • →Белая панель только там, где действуют: ввод вопроса, вход и регистрация, диалог.
