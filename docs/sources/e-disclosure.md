# e-disclosure.ru: итоги discovery (S1-12)

Дата: 28–29.09.2026. Данные: `scripts/discover_edisclosure.py`, снимки и сводка `summary.json` в `backend/tests/fixtures/edisclosure/`, справочник `backend/fixtures/reference/issuers.csv`. Числа ниже взяты из этих файлов и логов прогонов.

## Коротко

- Бота с честным User-Agent сайт не пускает: HTTP-клиент без браузера получает 403 на любой адрес, включая robots.txt. Chromium через Playwright в оконном режиме получает настоящие страницы, headless получает 403 или капчу.
- robots.txt запрещает `/api/*`, а поиск компаний работает через `/api/search/companies`. Бот компанию не ищет: id берётся из `issuers.csv`.
- Раздел с файлами отдаётся одной таблицей, пагинации нет. Раздел без файлов редиректит на карточку.
- У презентаций и пресс-релизов нет своего «типа документа». Их выдаёт строка описания под записью, в выборке только в разделе 10 «Прочие документы».
- Портал упаковывает каждый файл в zip. Эмитенты сами выкладывают rar (RAR5) и 7z. Имена внутри zip в UTF-8, иногда в cp866.
- 5 из 10 скачанных PDF РСБУ оказались сканами без текстового слоя.
- Итоги задевают §2, §3.2 (AD-11), §5.4, §8.5 и §10.2. Разрывы контракта в конце документа, все кроме сканов РСБУ закрыты в ядре v3 (PR #6).

## Как собрано

- `just discover-edisclosure` обходит выборку, `just discover-edisclosure --issuers` открывает только карточки и пишет справочник. Скрипт управляет видимым Chromium через Playwright 1.63 (тот же Chromium 1243, что у e2e фронта) и разбирает HTML через selectolax.
- Вежливость: сначала robots.txt с разбором `*` и `$` по RFC 9309, запросы по одному, пауза 2 с (`EDISCLOSURE_RPS=0.5`), страницы и архивы кэшируются между запусками. Поиск сайта скрипт не вызывает.
- Всего discovery сделал 241 запрос: проба без браузера 4, прерванный запуск 3, обход выборки 169 и 18, пересборка из кэша 2, справочник 45.
- Архивы (169 МБ) и разобранные строки лежат локально в `.discovery/edisclosure/`, в git не попадают.
- Снимки хранят только разметку. Сайт вписывает в DOM IP посетителя (`userIp` в параметрах Яндекс Метрики), реклама вписывает идентификаторы сессии, формы несут antiforgery-токены. Поэтому скрипт вырезает `script`, `style`, `iframe`, `noscript`, `link` и сторонние картинки и обнуляет `__RequestVerificationToken`. Таблицы и карточки разбираются так же, как до очистки. В `blocked_403.html` IP и ID запроса заменены.

## Доступ

1. **HTTP без браузера.** Запросы через urllib с User-Agent `KoriBot/1.0 (+mailto:…)` получили 403 от сервера Angie на robots.txt, поиск, карточку и список файлов. В теле страница «Forbidden» с текстом «If you are not a bot, please copy the report and send it to our support team». Снимок `blocked_403.html`, IP в нём заменён на 203.0.113.10.
2. **Браузер.** Chromium 153 со своим User-Agent получил все страницы без капчи. Все 54 файла скачаны запросом из контекста браузера (те же cookies и User-Agent) с ответом 200. Открытые проекты за сентябрь 2026 описывают перед сайтом JS-проверку ServicePipe (cookies `spjs`, `spsc`, `spid`); браузер проходит её сам.
   **Headless не проходит.** С родным User-Agent (`HeadlessChrome`) Chromium получает 403. С User-Agent, где `HeadlessChrome` заменён на `Chrome`, он проходит JS-проверку (cookies `spid`, `spjs`, `spsc`), а затем сайт уводит его на капчу `/xpvnsulc/?back_location=…` с текстом «Разверните картинку горизонтально» (cookie `rndcaptcha`). Проверено на двух карточках 29.09.2026. Поэтому ядро v3 держит браузер в оконном режиме, на сервере под Xvfb.
3. **robots.txt** (снимок `robots.txt`):

   ```
   User-Agent: *
   Disallow: /api/*
   Disallow: /Event/Certificate?*
   Disallow: /Company/Certificate/*
   Disallow: /PortalImageHandler.ashx?*
   Disallow: /Company/Search?*
   ```

   Crawl-delay нет. Карточки `portal/company.aspx`, списки `portal/files.aspx` и загрузка `portal/FileLoad.ashx` разрешены. `urllib.robotparser` сравнивает пути как префиксы и пропустил бы `/api/*`, поэтому скрипт разбирает правила сам.
4. **Условия использования** (`terms.html`). Правообладатель материалов сайта: Интерфакс-ЦРКИ, кроме информации, которую эмитенты раскрывают по закону. Для материалов Интерфакса нужна гиперссылка на главную страницу сайта, переработка запрещена, кроме сокращения. Автоматический доступ условия не регулируют. Отчётность эмитентов под эти ограничения не попадает, ссылку на источник §8.5 требует и так.
5. **Платный «Шлюз Раскрытие»** (`api-gateway.html`): REST API, JSON, Swagger. Данные о публикации файлов и отчётов: 16 180 ₽ в месяц без НДС, подписка от 3 месяцев. Сообщения вместе с отчётами: 27 000 ₽ в месяц или 24 750 ₽ при оплате за 12 месяцев. Архив до 01.07.2020: +50% к тарифу. Сайт пишет, что лимит запросов к шлюзу выше, чем к общедоступному сайту.
6. По выдаче веб-поиска часть эмитентов ведёт страницу на домене третьего уровня: `rostelecom.`, `yandex.`, `positive.`, `samolet.e-disclosure.ru`. Карточки и разделы на портале у них тоже есть.

## 1. Как найти компанию по ИНН и названию

Форма `/poisk-po-kompaniyam`, `#searchCompanyForm` (снимок `search/page.html`):

- `textfield`: «Название компании, руководитель или код», подсказка «возможны коды: ИНН, ОГРН, ОКПО, эмитента»;
- фильтры `radReg` (`FederalDistricts` или `Regions`), `districtsCheckboxGroup`, `regionsCheckboxGroup`, `branchesCheckboxGroup`, значение `-1` означает «все»;
- скрытые поля `lastPageSize=10`, `lastPageNumber=1`, `query`.

Скрипт страницы (`search/ed.search.companies-page.js`) шлёт `POST api/search/companies` с сериализованной формой и `Accept: application/json`. Ответ JSON рендерит шаблон `foundcompanieslist.nunj`, страницы переключает `div.paging a[data-link-page]`, размер страницы задаёт `select[name=pageSize]`. При перегрузке сервер отвечает 500 с `{"error": 1}`.

robots.txt запрещает `/api/*`, поэтому бот поиск не вызывает. Discovery его тоже не вызывал, так что формат ответа не снят.

Рабочий путь: id компании хранит справочник `issuers.csv`. Для 52 эмитентов id нашёлся в выдаче веб-поиска по домену e-disclosure.ru (ссылки `company.aspx?id=`), затем бот открыл каждую карточку и сверил ИНН. Совпали все 52. Новый эмитент добавляется так же или вручную (`cli bind-issuer`, F-10).

Карточка `portal/company.aspx?id=<id>`: сокращённое имя в `.infoblock h2`, блок «Общие сведения» в `table.company-table`, подпись в `td.field-name`, значение в соседней ячейке. `<title>` на всех страницах одинаковый, имени компании в нём нет.

| Подпись на сайте | Поле `DisclosureCompany` (§8.5) |
|---|---|
| Полное наименование компании | `full_name` |
| Сокращенное наименование компании | `short_name` |
| ИНН | `inn` |
| Номер Государственной регистрации (ОГРН) | `ogrn` |
| Адрес Субъекта раскрытия, указанный в ЕГРЮЛ (у части эмитентов только «Место нахождения») | `address` |
| Адрес страницы в сети Интернет | `page_url` |

Кроме них на карточке есть «Адрес (почтовый адрес)», «Дата государственной регистрации», «Зарегистрировавший орган», «ФИО руководителя», «Телефон руководителя» и «Сведения о регистраторе». У иностранного эмитента (En+ Group plc) строк ИНН и ОГРН нет. Меню карточки ссылается на разделы `files.aspx?id=<id>&type=<n>`.

## 2. Как устроены таблица файлов и пагинация

Адрес раздела: `portal/files.aspx?id=<id>&type=<n>`. Раздел без файлов отвечает редиректом на карточку: 21 из 115 страниц разделов в выборке.

Пагинации нет: `div.pagingblock` пустой, все строки на одной странице. Самая длинная страница: «Эмиссионные документы» Сбербанка, 1823 строки и 2,4 МБ HTML.

Строка таблицы `table.files-table`:

- `td.row-number-cell`: номер;
- `td.type-cell`: тип документа, в тексте бывают двойные пробелы («Дополнительная  информация…»);
- колонки периода и дат (`td.date-cell`), набор зависит от раздела;
- `td.file-cell > a.file-link`: `href=https://www.e-disclosure.ru/portal/FileLoad.ashx?Fileid=<id>`, `data-fileid=<id>`, текст `zip, 2.31 МБ` с неразрывными пробелами;
- `td.cert-cell`: кнопка «Данные о подписи» (`data-doc-id=<id>`).

У записи с описанием номер и файл занимают `rowspan="2"`, а следующая строка `tr.description-row` несёт свободный текст. Описание есть у 1287 из 6831 строки. Заголовки колонок содержат мягкие переносы (`\xad`).

## 3. Что лежит в архивах

Портал сам упаковывает каждый загруженный файл в zip: `Content-Disposition: attachment; filename=MSFO_6m2026.pdf.zip; filename*=UTF-8''MSFO_6m2026.pdf.zip`. Имя в заголовке транслитерировано, исходное имя на кириллице лежит внутри архива. rar и 7z выкладывает сам эмитент, портал отдаёт их как есть: у Норникеля все 5 скачанных файлов оказались RAR5 с одним PDF внутри.

Скачано 54 файла, по 5 на эмитента и 4 у En+ Group plc: 49 zip и 5 rar. Внутри zip:

- 46 PDF и ещё один PDF на 62 МБ (годовой отчёт Сбербанка, в разбор не попал);
- 2 XML: XBRL ESG-отчётности Сбербанка (`XBRL_<ОГРН>_ep_nso_em_esg_y_<дата>.xml` и `Service_…xml`);
- 1 DOCX.

Вложенных архивов и отдельных файлов подписи (`.sig`, `.p7s`) в выборке нет: подпись показывает сайт кнопкой «Данные о подписи».

Имена внутри zip: 36 с флагом UTF-8, 10 в ASCII, 4 в cp866 без флага (архивы, которые эмитент собрал Windows-архиватором). В RAR5 имена всегда в UTF-8.

PDF (pypdf):

- РСБУ: у 5 из 10 файлов (Сбербанк, ЛУКОЙЛ, РЖД, РУСАЛ, «Яндекс») нет текста ни на одной странице, только изображения. Это сканы: в поле Producer стоят Xerox VersaLink, Canon, PDF24 и ContentReader. Газпром, Роснефть, Магнит, Норникель и МТС отдают текст.
- МСФО и годовые отчёты в выборке с текстовым слоем.
- МСФО МТС зашифрован с пустым паролем пользователя (AES): pypdf читает его только с пакетом `cryptography`.

## Справочник issuers.csv

- Путь `backend/fixtures/reference/issuers.csv`: UTF-8, LF, кавычки по RFC 4180, 52 эмитента.
- Колонки: `ticker` (тикер акции на MOEX), `edisclosure_id`, `inn`, `ogrn`, `name` (полное наименование), `short_name`. Значения, кроме тикера, взяты с карточки.
- `asset_uid` в файле нет: его отдаёт только T-Invest (L-05). F-10 найдёт `asset_uid` по тикеру в `instruments`.
- Состав отражает индекс IMOEX и популярные бумаги по состоянию знаний сессии. С официальным составом индекса его не сверяли.
- Пересборка: `just discover-edisclosure --issuers`, по одному запросу на карточку, которой нет в кэше.

## Что это значит для следующих задач

- **S1-09, адаптер `disclosure/edisclosure/`.** httpx получит 403. Владелец выбрал браузерный транспорт без KoriBot (ядро v3): Chromium в оконном режиме, в образе api под Xvfb. Проходит ли он с IP VPS без капчи, проверяет S1-13; платный шлюз остаётся запасным вариантом (L-06).
- **S1-09.** `search_companies` не реализовать без нарушения robots.txt (разрыв 1).
- **F-10.** Разбирать `td.type-cell` вместе с `tr.description-row`, добавить раздел 10 (разрыв 2). Распаковщику нужны RAR5 и 7z (разрыв 4) и определение cp866 в именах без флага UTF-8.
- **F-11.** Половина файлов РСБУ в выборке без текстового слоя, разбор по кодам строк (AD-11) их не прочитает. Варианты: OCR (Tesseract) или другой источник РСБУ, например ГИР БО ФНС (bo.nalog.ru). Нужен ADR на AD-11 (разрыв 4).
- **F-12, F-13.** Зашифрованные PDF читаются с `cryptography`, она уже есть в стеке.
- **Golden-тесты F-10** строятся на снимках этой папки. Ожидания выписываются вручную из снимков, не из вывода скрипта (§14.1).
