## Разбор

- **Окна контекста.** Все четыре семейства приняли самую длинную пробу скрипта, около 121,6 тыс. токенов из 128 тыс. Настоящее окно может быть больше. По построению пробы стоят около 152 тыс. токенов на семейство, точные числа лежат в `llm_calls` VPS.
- **Tavily.** Поиск получил `ForbiddenError` без текста ошибки. `tavily-python` 0.8.4 бросает его на ответы 403, 432 и 433 и берёт текст из `detail.error` тела ответа, здесь поле пустое. Адаптер (`gateways/web/tavily.py`) переводит любой из трёх ответов в `web_credits_exhausted`. С рабочей машины поиск прошёл 08.10.2026 (`smoke-2026-10-08.md`), без ключа API отвечает этому VPS 401 (S1-13). Причина не установлена: кончились кредиты или Tavily отказывает IP сервера. Проверка: остаток кредитов в кабинете Tavily, затем один запрос с VPS с выводом статуса и тела ответа. Отдельно: при отказе 403 агент скажет пользователю, что кончились кредиты. Отличить 403 от 432 и 433 адаптер может только по статусу ответа, правка нужна до F-15 в режиме owner.
- **e-disclosure.** Капча с первого захода: `edisclosure_blocked`, `captcha: true` на профиле сервера. В S1-13 капча пришла и на чистом профиле. Попытка одна, по решению владельца, чтобы не портить репутацию IP.
