## Разбор

- **Окна контекста.** Все четыре семейства приняли самую длинную пробу скрипта, около 121,6 тыс. токенов из 128 тыс. Настоящее окно может быть больше. По построению пробы стоят около 152 тыс. токенов на семейство, точные числа лежат в `llm_calls` VPS.
- **Tavily.** Поиск напрямую с IP сервера получил `ForbiddenError` без текста ошибки. `tavily-python` 0.8.4 бросает его на ответы 403, 432 и 433 и берёт текст из `detail.error` тела ответа, здесь поле пустое. Адаптер образа `sha-0a8ea37` переводил любой из трёх ответов в `web_credits_exhausted`. С рабочей машины поиск прошёл 08.10.2026 (`smoke-2026-10-08.md`), без ключа API отвечает этому VPS 401 (S1-13). Повтор через xray 22.10 показал отказ по адресу сервера, а не нехватку кредитов (раздел ниже).
- **e-disclosure.** Капча с первого захода: `edisclosure_blocked`, `captcha: true` на профиле сервера. В S1-13 капча пришла и на чистом профиле. Попытка одна, по решению владельца, чтобы не портить репутацию IP.
- **Прогрев профиля (L-06).** В тот же день владелец прошёл капчу руками: Firefox адаптера с профилем сервера в разовом контейнере, экран через noVNC и SSH-туннель. Капча пришла дважды подряд, затем в той же сессии браузера открылись карточка (ПАО Сбербанк, ИНН совпал) и список МСФО (8 документов, последний от 29.07.2026). Cookies проверки `spid`, `spsc`, `spjs` записаны до 25.11.2027, cookies капчи `spca`, `spcajs`, `rndcaptcha` сессионные. Через две минуты новый процесс Firefox на этом профиле снова получил капчу (`edisclosure_blocked`, 67 с). С IP сервера пропуск живёт только в сессии браузера, а процесс api перезапускается на каждом деплое: разовый прогрев для F-10 не годится.

## Tavily через xray: 22.10.2026

С core v12 (PR #33 и #34) адаптер Tavily ходит с VPS через сервис `xray` (`TAVILY_PROXY_URL=http://xray:8080`): балансер выбирает ноду VLESS из подписки владельца по наименьшей задержке. Скрипт из `main` ушёл по stdin в разовый контейнер образа `kori-api:sha-350f323` с флагом `--only tavily`: `compose.sh run --rm -T --no-deps -e PYTHONPATH=/app api`. Модель скрипт не вызывал, на e-disclosure не заходил.

| Ноды | Проверка | Итог | Подробности |
|---|---|---|---|
| 9: вся подписка | Tavily: поиск через TAVILY_PROXY_URL | ошибка | PermanentGatewayError(web_unavailable); ForbiddenError:  |
| 7: без московской ноды и ноды автовыбора | Tavily: поиск через TAVILY_PROXY_URL | ok | результатов 3, кредитов 1 |

- **Причина отказа.** Ключ тот же, кредиты есть: через зарубежную ноду поиск прошёл. Tavily решает по адресу выхода: 403 без текста получили IP сервера 21.10 и, вероятно, московская нода 22.10, которую балансер выбрал как ближайшую к VPS. Владелец убрал обе ноды из подписки на VPS.
- **Адаптер.** С PR #34 он отличает 403 от лимитов по статусу ответа: 403 даёт постоянную ошибку `web_unavailable`, 432 и 433 дают `web_credits_exhausted`. При отказе по адресу агент не скажет пользователю, что кончились кредиты.
